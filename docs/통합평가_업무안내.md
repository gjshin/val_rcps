# 평가 앱 사용 안내

버전 2026.09.29-calculation.2

## 1. 입력·시장자료

새 평가 또는 기존 JSON 파일을 불러옵니다. 계약조건, 행사기간, 주가, 변동성, 금리를 입력합니다.
계약 해석·판단은 대화에서 검토한 뒤 필요한 숫자를 입력합니다. 앱에는 계약서 업로드나 외부 AI 분석 절차가 없습니다.
기존 파일의 검토기록은 데이터 손실을 막기 위해 보존하되 화면·출력의 필수 조건으로 사용하지 않습니다.

- 전환·신주인수권과 투자자 상환청구권 체크 시 바로 상세 입력이 열립니다.
- 전환, 상환청구 및 콜 행사방식은 기간 중 언제든지 / 특정일 / 지원 권리의 정기 행사로 구분합니다.
- 월·2주·주 간격을 선택할 수 있습니다. 실제 계산은 만기를 포함한 등간격 격자이고 평균 일수·구간 수를 결과에 표시합니다.
- 주가에 희석을 이미 반영한 경우 보통주·전환 증가 주식수는 확인사항용입니다. 이 숫자만으로 노드 가격을 추가 희석하지 않습니다.
- 주가·변동성·금리 도구는 **입력·시장자료 → 주가·변동성·금리 자료**에 있습니다.
- 출처·평가가정은 필요할 때 입력합니다. 검토 완료나 작성자·검토자 승인은 요구하지 않습니다.

### 변동성

종목 또는 피어, 평가기준일, 조회 일수, 연 거래일수, 이상치 제거 방법을 정하고 **주가 받기**를 누릅니다.
수치를 확인한 다음 **이 변동성을 현재 평가에 적용**을 누릅니다. 다른 필수값이 아직 비어 있어도 변동성은 적용할 수 있습니다.
일부 조회 실패·누락을 제외하려면 **자료 누락 처리**에서 해당 옵션을 먼저 선택합니다. 실제 사용 관측치와 제외내역이 조서에 남습니다.
상장사 평가에는 대상회사 원본 주가도 포함됩니다. 산출내역 엑셀은 별도 버튼으로 생성합니다.

## 2. 평가·분석

**현재 입력으로 평가**를 누릅니다. 입력 변경만으로 재계산하지 않습니다.
금액, 원금 100 기준 구성요소, 산술 검산과 확인할 사항을 확인합니다.

| 필요한 기능 | 위치 |
|---|---|
| 격자·금리곡선·주가 자료·의사결정·추가 수치 검산 | 상세 계산·회계 참고표 |
| 상환금액·상각후원가, TF·BDT 부채요소, 제3자 콜 방법 비교 | 상세 계산·회계 참고표 → 권리·금리 분석 |
| 주가·변동성·금리 민감도 | 추가 분석 → 민감도 계산 |
| 부분상환·지급시차·누적배당 및 전액상환 일정 | 계약조건 시나리오 |
| 회차 합산·전기 대비 변동 | 왼쪽 여러 회차·변동 분석 |

BDT 적용, 내재파생 분리 등은 비율만으로 자동 결정하지 않습니다. 지원하지 않는 조합은 입력 오류로 안내합니다.
표준화하기 어려운 계약조건은 기본 계산 조서를 출력한 뒤 업무파트너와 별도 검토합니다.

## 3. 조서 출력

**기본 값 / 상세 계산 값 / 상세 계산 수식** 중 고르고 **조서 생성 → Excel 조서만 저장**을 누릅니다.
필요하면 **회계처리·분개·상각표 포함 (초안)**을 선택합니다. 투자자 전기 장부금액 등 필요한 값이 없으면 분개 미산출 사유를 표시합니다.
검토기록·판단근거·계약반영표·확정상태·독립검산대사 시트는 출력하지 않습니다.
상세 조서는 평가와 같은 격자를 사용합니다. 주 간격의 장기 평가에는 시간이 걸릴 수 있습니다.
수식 조서는 가정 시트의 노란 칸을 바꾸면 결과·회계처리·상각표(유효이자율 포함)까지 다시 계산됩니다.
앱 값과의 대사는 `tools/run_case.py --check-formulas`(LibreOffice 재계산)로 합니다 — 결과 시트의 주요 칸과
상각표 유효이자율을 앱 값과 견줍니다. 실제 Microsoft Excel 에서의 확인은 따로 해야 합니다.

종료 전 **평가파일 저장**으로 입력 JSON을 보관합니다. 고객 계약서·평가 입력·조서는 공개 코드 저장소에 올리지 않습니다.
