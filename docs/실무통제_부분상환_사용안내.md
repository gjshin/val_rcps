# 시장자료·부분상환 사용 안내

현재 앱은 입력·시장자료 → 평가·분석 → 조서 출력의 3단계입니다.
검토기록·작성자/검토자 승인·최종 확정은 조서 생성 조건이 아닙니다.

## 변동성 자료

「입력·시장자료 → 주가·변동성·금리 자료 → 변동성 산출」에서 조회하거나 수정종가 파일을 읽습니다.
엄격한 검사가 기본입니다. 일부 실패 종목과 빈 날짜를 제외하려면 해당 옵션을 선택합니다.
사용 종목·실제 관측치·누락 일자·조회실패 사유·이상치 제외와 취득조건은 JSON 및 Excel에 기록됩니다.
최종 주가가 7일 이상 오래된 경우 엄격 모드는 차단하며 누락 허용 시 표시 후 진행합니다. 유효 가격 10개 이상은 필요합니다.
0·음수·비유한 가격·중복·미래 날짜는 옵션과 관계없이 거부합니다. 파일의 전체 역순은 날짜순으로 정리합니다.
빈 날짜를 제외하면 연속 유효 가격 간 수익률을 사용하므로 거래정지 등 긴 공백의 영향은 원자료와 함께 확인합니다.
조회 이력이 없는 이전 변동성 패키지는 현재 도구에서 재산출합니다.

## 3. 부분상환·지급시차·누적배당

전에 있던 「평가·분석 → 계약조건 시나리오」 화면은 없앴습니다. 결과가 평가금액과 수식 조서에 들어가지 않는 별도 계산이었고, 상환 재원 제한·못 갚은 금액 이월·지연 가산·만기 미상환 처리는 이제 상환청구권 아래 «배당가능이익 반영» 에서 평가에 직접 반영합니다(`docs/입력안내_RCPS.md`). 예전 평가파일에 저장된 일정은 지우지 않으며 조서에 기록으로 남습니다.

## 조서 출력

현재 입력으로 계산한 뒤 기본 값·상세 값·상세 수식 중 선택해 생성합니다.
회계처리 초안은 선택 시 포함하고 계약별 최종 회계판단은 별도 검토합니다.
부분상환 결과는 명시한 일정에 따른 조건부 분석이므로 기본 RCPS 값에 자동 합산하지 않습니다.
