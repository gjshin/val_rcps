# 시장자료·부분상환 사용 안내

현재 앱은 입력·시장자료 → 평가·분석 → 조서 출력의 3단계입니다.
검토기록·작성자/검토자 승인·최종 확정은 조서 생성 조건이 아닙니다.

## 변동성 자료

「입력·시장자료 → 주가·변동성·금리 자료 → 변동성 산출」에서 조회하거나 수정종가 파일을 읽습니다.
엄격한 검사가 기본입니다. 일부 실패 종목과 빈 날짜를 제외하려면 해당 옵션을 선택합니다.
사용 종목·실제 관측치·누락 일자·조회실패 사유·이상치 제외와 취득조건은 JSON 및 Excel에 기록됩니다.
최종 주가가 7일 이상 오래된 경우 엄격 모드는 차단하며 누락 허용 시 표시 후 진행합니다. 유효 가격 10개 이상은 필요합니다.
0·음수·비유한 가격·중복·미래 날짜는 옵션과 관계없이 거부합니다. 파일의 전체 역순은 날짜순으로 정리합니다.
빈 날짜를 제외하면 연속 유효 가격 간 수익률을 사용하므로 거래정지 등 긴 공백의 영향은 원자료와 함께 확인합니다.
조회 이력이 없는 이전 변동성 패키지는 현재 도구에서 재산출합니다.

## 3. 부분상환·지급시차·누적배당

「평가·분석 → 계약조건 시나리오 → 부분상환·지급시차·누적배당」에서 분석을 만든다.
현재 평가의 필수 입력이 완성되어야 하며 RCPS·TF만 지원한다.

| 입력 | 의미 |
|---|---|
| 분석 종료일 | 잔존 물량의 최종 전환 또는 상환청구 시점. 계약 만기보다 이른 종료는 지원하지 않음 |
| 기초 미지급배당 | 기준일 잔존 물량의 원금 100당 미지급 잔액 |
| 기초 기지급배당 누적 | 남은 각 주식에 귀속되는 과거 지급배당의 원금 100당 합계 |
| 미지급배당 가산이율 | 별도 약정이 있을 때만 입력. 상환이율이나 지연배상률을 자동으로 사용하지 않음 |
| 상환이율 | 발행일부터 청구일까지 실제일수/365, 연복리 적용 |
| 상환 시 미지급배당 | 약정 상환금에 이미 포함됐는지, 별도 가산하는지 선택 |
| 연장 중 권리 | 연장 중 전환권·상환청구권의 존재를 각각 명시 |
| 배당 발생·지급 | 해당 사건일 현재 잔존 물량의 원금 100당 금액 |
| 상환비율 | 해당 사건일 잔존 물량 중 청구 비율. 절반이면 0.5, 나머지 전량이면 1 |
| 실제 지급일 | 청구일부터 지급일까지 할인. 청구 이후 해당 물량은 전환할 수 없다고 가정 |
| 이익·현금 한도 | 최초 분석 물량의 원금 100당 금액. 해당 회차·지급건에 배분 가능한 금액 |
| 조정 전환가액 | 확정 또는 가정한 사건 후 주당 전환가액. 0이면 유지 |
| 지연 가산 | 가산 연이율과 시작일을 모두 명시. 12%는 일정표에서 0.12 입력 |

각 사건일의 예정 상환액은 다음과 같다.

`잔존 원금 100당 상환금 = 100 × (1 + 상환이율)^(발행일→청구일 실제일수/365) − 차감 대상 기지급배당 + 별도 가산 대상 미지급배당`

이 금액에 최초 물량 대비 해당 상환비율을 곱하고, 명시한 지연 가산을 반영하여 실제 지급일에 할인한다.
배당 지급은 같은 날 상환·전환 비교보다 먼저 발생한다고 가정한다. 이 사건 순서와 청구 후 권리 소멸이 실제 계약과 다르면 이 분석을 그대로 적용할 수 없다.

예를 들어 최초 물량 100% 중 40%를 먼저 청구하고 다음 해 나머지를 전량 청구하면 상환비율은 첫 행 0.4, 둘째 행 1이다.
현금흐름 대사표에는 최초 물량 대비 40%, 60%로 표시된다. 둘째 행에 0.6을 입력하면 잔존 60%의 60%인 36%만 추가 청구된다.

각 지급건의 이익·현금 한도가 지급액보다 작으면 계산을 중단한다. 한도를 여러 지급건에 중복 배분하지 않았는지 평가자가 별도로 대사한다.
현재 버전은 회사 전체 이익·현금의 시간별 공동 예산을 자동 관리하지 않는다.

일정은 기준일 이후 날짜순으로 입력하고 종료일 행을 포함한다. 상환 없는 행의 지급일·가산 시작일은 비운다.
상환청구 종료일 뒤의 실제 지급도 할인한다. 이미 기준일 전에 청구된 미수금은 잔존 RCPS와 구분하여 별도로 평가한다.

청구 전 전환과 예정 상환을 비교하고, 청구한 물량은 전환권에서 제외한다. 이후 잔존 물량을 전환해도 앞서 확정된 상환 미수금이 없어지지 않는다.
상환비율은 사용자가 입력한 조건부 일정이다. 주가별 최적 상환비율이나 이익·현금·주가의 공동 확률모형을 구한 결과가 아니다.
콜·정기 리픽싱·IPO·BDT 조건과의 결합은 차단한다. 청산배분·회차 간 상호 희석·계약위반 발생확률도 포함하지 않는다.

주가 비교는 동일 시간 간격의 격자에 사건을 이연하여 적용한다. 같은 격자에 두 사건일이 겹치면 간격을 줄여야 한다.
고정 현금흐름은 실제 날짜로 할인하도록 조정하지만, 전환·상환 비교에는 격자 근사가 남는다. 간격을 줄인 결과와의 수렴 대사가 필요하다.
부동소수점 오차 수준의 동률(비교금액 × 1e-12 이내)은 예정 일정의 계속보유로 처리한다. 동률에서 임의로 전환하여 TF의 현금·주식 할인 갈래가 바뀌는 것을 방지한다.
결과 화면의 최대 사건일 이연과 신용금리곡선 밖 지급일 여부를 확인한다.

## 조서 출력

현재 입력으로 계산한 뒤 기본 값·상세 값·상세 수식 중 선택해 생성합니다.
회계처리 초안은 선택 시 포함하고 계약별 최종 회계판단은 별도 검토합니다.
부분상환 결과는 명시한 일정에 따른 조건부 분석이므로 기본 RCPS 값에 자동 합산하지 않습니다.
