# 계산 중심 화면 개편과 기존 기능 위치

2026-09-29: 계약 검토와 계약별 판단은 업무파트너와 대화에서 수행하고 앱은 계산·수치 확인·출력에 집중하도록 변경했습니다.

| 업무 | 현재 위치 |
|---|---|
| 계약 숫자·행사일·시장자료 입력 | 평가 작업 → 입력·시장자료 |
| 주가·변동성·금리 도구 | 입력·시장자료 → 주가·변동성·금리 자료 |
| 평가·산술 검산·수치 경고 | 평가·분석 |
| 격자·금리·회계 참고표 | 평가·분석 → 상세 계산·회계 참고표 |
| 분리 판정·권리표·행사 진단·콜 방법·우선순위·BDT·추가 검토·근거 원문 | 상세 계산·회계 참고표 → 판단·근거 |
| 최초 인식 차이·보정 기록·이어 적용 | 평가·분석 결과 상단 / 주가·변동성·금리 자료 → 주가 역산·보정 이어 적용 |
| 부분상환·지급시차·누적배당 | 평가·분석 → 계약조건 시나리오 |
| 회차 합산·전기 변동 대사 | 여러 회차·변동 분석 |
| 계산 조서·선택 회계처리 초안 | 조서 출력 |

검토조서·판단근거·최종확정은 현재 업무 흐름에서 제외했습니다. 옛 파일의 기록은 읽기·저장 호환성을 위해 보존합니다.
과거 검증기록은 당시 버전의 기록입니다. 현재 화면과 출력 구성은 README와 통합평가_업무안내.md를 기준으로 봅니다.

기존 월 격자의 가치 산식은 유지하며 주·2주 간격을 명시적으로 추가했습니다. 수식 조서의 격자나 리픽싱 방법을 자동 축소·변경하지 않습니다.
계약·기준서 해석은 계산 기능 밖에서 검토합니다. 수치 비교가 회계분류나 모형 선택의 자동 결론으로 표시되지 않도록 했습니다.

## 2026-09-29 (2) 판단 보조 복원

앱이 무겁고 판단 서술이 길다는 이유로 빠졌던 판단 보조를 되살렸습니다. 원칙은 세 가지입니다.

- 판정은 한 줄로 쓰고 숫자와 근거 문단을 붙입니다. 긴 설명은 펼침 안에 둡니다.
- 격자를 다시 도는 비교는 버튼을 눌렀을 때만 계산합니다. 판단·근거 탭은 추가 격자 계산 없이 열립니다(옵션 없는 격자 한 장 제외).
- 앱 판정은 초안입니다. 평가자 판단(동의·수정·해당 없음)과 근거 한 줄을 평가파일(`memos`)과 조서 「판단·근거」 시트에 남깁니다.

근거 원문은 `valuation/refdata/`에 있습니다. `kifrs.json`은 회계위키 수록 본문과 대조했고, 공식 본문은 한국회계기준원에서 최종 확인해야 합니다. `book_pages.json`은 한공회 Series 11의 해당 쪽 발췌이며 외부 배포 금지입니다. 발췌에 쓴 PDF의 SHA256은 파일에 기록했습니다.
GPT 1차 개편의 검토기록·최종 확정 단계는 되살리지 않았습니다. 판단근거 12주제는 판단·근거 탭의 추가 검토 항목으로 합쳤습니다.
