# V2 동료 검토 버전

버전: 2026.10.06-v2.1-preview. 기존 운영 앱을 교체하지 않는 별도 검토 버전입니다.

## 바뀐 작업 흐름

- 입력 → 평가결과 → 계산내역 → 조서 출력의 네 화면으로 정리했습니다. 세션 반영과 파일 저장을 구별하고 합성 사례로 시작할 수 있습니다.
- 총액·주당·원금 100을 전환합니다. 권리별 증분, TF 주식/현금결제분, 회계 인식액을 구별합니다.
- 계산내역은 현재 평가 실행의 실제 노드와 자식 노드, 확률·금리·할인계수·지급액을 사용합니다. 조회 시 다시 평가하지 않습니다. 콜 반영 전 본체 트리를 표시합니다.
- 입력 변경 시 이전 결과임을 표시하고 재평가 전 조서를 차단합니다. 저장된 메모는 현재 조건/이전 조건/작성 조건 미확인을 구별합니다. 과거 메모는 보존합니다.
- 조서 목차, 실행번호, 문서 개정번호, 계산대사, 금리·행사일정 및 실제 계산근거 기록을 추가했습니다.

## 계산·출력 수정

1. 분리 비교의 상각후원가를 다음 지급일 잔액으로 대체하던 문제를 수정했습니다. 직전 지급일 잔액을 실제 행사시점까지 이연합니다.
2. 콜 분리 비교에 전체 행사일을 포함했습니다. 첫 행사일만으로 결론을 내리지 않습니다.
3. 배당가능이익으로 지급이 지연될 때 행사 진단에서 실제 지급가치와 별도 이자를 사용합니다.
4. 일반기업회계기준·전환 대응 등 과거 메모를 출력하고 조건 변경 후의 기록을 구별합니다.
5. 선택형 메모와 수치 계산근거를 분리했습니다. 메모를 빼도 수치 분리 비교는 남습니다.
6. 부트스트래핑 결과 할인계수가 0 이하인 곡선을 계산 전에 차단합니다. 유효한 음수 금리는 허용합니다.
7. 미입력 배당가능이익 연도가 실제 지급에 사용되면 가정·근거를 명시하기 전 출력을 차단합니다. 미해결 계약조건도 출력하지 않습니다.

## Excel 편집 범위

수식 조서에서 직접 입력된 주가와 주가 변동성만 노란색 편집 셀로 열어 둡니다. 날짜, 행사 조건, 금리, 만기 구성, 격자, 모형 등은 앱에서 변경한 뒤 새로 생성합니다. 자료에서 산출한 변동성은 앱의 자료 도구에서 변경합니다. 시트 보호는 실수를 막기 위한 것이며 암호 보안을 제공하지 않습니다.

계산대사의 앱값, 계산근거, 금리 적용내역, 행사 지급내역, 메모는 생성 당시의 고정 기록입니다. Excel 입력을 바꾸면 결과 수식은 바뀌지만 이 기록과 실행번호는 바뀌지 않습니다. 변경 결과를 정식으로 보관하려면 앱에서 다시 평가·출력합니다. 값 조서는 재계산되지 않습니다.

## 검증

- 기존 평가·화면·출력 시험과 이번 6개 오류군의 회귀시험을 실행했습니다.
- Microsoft Excel 전체 재계산: RCPS TF/GS, CB, BW, 행사시점 상각후원가, 전체 콜 행사일, 배당가능이익 제약, 주 단위, 주주간계약 9개 합성 사례. 평가값과 주요 중간 셀이 앱값과 일치했습니다.
- TF 주가, TF 변동성, GS 주가를 기존 Excel 조서에서 변경한 3개 추가 사례도 앱 재평가 결과와 일치했습니다.
- 9개 조서의 저장 셀 289,136개에서 Excel 오류 값이 없었습니다. 이는 모든 계약 조합의 적정성을 입증하지는 않습니다.
- LibreOffice가 없어 해당 프로그램 전용 재계산 시험은 생략합니다. Excel 검증으로 별도 보완했습니다.

기준 커밋으로 별도 체크아웃하거나 전달한 Git bundle을 새 폴더에 복원합니다. 기존 작업 폴더를 강제 초기화할 필요가 없습니다.

## 동료 시험과 상용 전환

합성·익명 사례로 입력 완료, 단위 대사, 노드 추적, 입력 변경·재평가, 값/수식 조서 출력, 파일 재열기를 확인합니다. 금융상품별 독립 평가모형과의 실무 대사 및 검토자 피드백은 다음 단계입니다.

이 버전에는 사용자별 로그인, 서버 영구 저장, 이용자별 접근권한, 결제·서비스 운영 기능을 추가하지 않았습니다. 현재 전달 주소는 PC 내부 주소이며 외부 동료에게 그대로 전달할 수 없습니다. 동료의 별도 실행 또는 검토용 배포가 필요합니다. 상용 운영 전에는 이 운영 범위와 지원 계약 조합을 확정해야 합니다.
