# 계약서를 입력 칸으로 옮기는 법 — 차바이오텍 RCPS 를 예로

사이드바 위쪽 **시나리오 불러오기** 에
[`시나리오/차바이오텍_RCPS_2024-05-16.json`](../시나리오/차바이오텍_RCPS_2024-05-16.json)
을 넣으면 아래 값이 한 번에 들어간다. 손으로 넣고 싶거나 다른 계약을 넣을 때는
이 문서를 표로 따라가면 된다.

칸 이름은 **상품 = RCPS** 를 고른 뒤의 이름이다. CB 를 고르면 같은 칸이
「표면이자율 · 조기상환청구권 · 매도청구권」으로 바뀐다.

## 0. 먼저 정할 것 — 금액의 기준

이 앱은 **1주 발행가를 100 으로 놓고** 모든 값을 잰다. 주식 수를 넣는 칸은 없다.
발행총액만 넣으면 조서가 원화로 환산해 준다.

## 1. 모형

| 칸 | 값 | 근거 |
|---|---|---|
| 상품 | 상환전환우선주 (RCPS) | |
| 신용위험 처리 | TF | 실무 표준. GS 는 비교용으로 화면에 함께 나온다 |
| 조정일 아닌 시점 | 상태확장(정확) | 리픽싱 주기 7개월이 노드에 안 떨어진다. 근사법은 값을 낮게 잡는다 |
| 전환권 회계 분류 | **파생상품부채** | 7개월 주기 하향 리픽싱이 있어 확정수량 대 확정금액 요건을 못 맞춘다 |

리픽싱이 없는 계약이라면 전환권 회계 분류를 **자본**으로 두는 것이 보통이다.
어느 쪽인지는 「분리 판단」 탭이 계약 조항으로 짚어 준다.

경과 0.0개월 · 잔존 5.00년 · 노드 60 이 화면에 뜨면 맞게 들어간 것이다.

**우선배당률을 액면 기준으로 넣으면 안 된다.** 계약서는 「액면가 500원의 연 1%」
라고 쓰지만 이 앱의 100 은 발행가다. 500 × 1% ÷ 17,354 = 0.0288% 를 넣어야 현금흐름
크기가 맞는다. 1% 를 그냥 넣으면 배당이 35배로 부풀어 오른다.

**보장수익률을 비워 두면 안 되는 이유.** 만료 시 자동전환이라 만기에 현금이 없지만,
순차 차감의 출발점인 「옵션 없는 우선주부채」(B0)는 전환권을 뗀 채무라 보통주가 될 수
없다. 그래서 만기에 상환받는 것으로 잰다. 이 값이 B0 를 정하고, B0 가 주계약과 파생의
경계를 정한다. 차바이오텍의 경우 회사도 **상환청구 가능 최종일(2029-04-16)의
상환가액 107.639%** 를 만기 현금흐름으로 썼다.

## 4. 전환 · 조정

| 칸 | 값 | 근거 |
|---|---|---|
| 전환 시작 (개월) | 12 | 발행 1년 후 = 2025-05-16 |
| 전환 종료 (개월) | 59 | 존속기간 만료 1개월 전 = 2029-04-16 |

시작·종료는 **날짜로 넣어도 된다.** 「날짜 · 기간」 맨 위의 「행사 시점 입력 방식」을 날짜로
두면 전환·조기상환·매도청구·의무보유·예상 상장 칸이 달력으로 바뀌고, 앱이 발행일 기준
개월로 바꿔 저장한다(옆에 «발행일 기준 12.0개월» 로 보여 준다). 계약서는 날짜로 쓰여
있으므로 날짜로 넣는 쪽이 세는 실수가 적다. 시나리오 파일과 조서는 어느 쪽으로 넣어도
같다 — 저장되는 것은 개월이고, 조서 가정 시트에는 개월과 날짜가 함께 실린다.
권리가 없는 계약이면 「이 권리 없음」을 켠다. 주기(조정 주기·상환 주기·이자 지급주기)는
날짜가 아니므로 개월 그대로다.
| 조정 방식 | 하향+상향 | 계약에 상향 재조정 조항이 함께 있다 |
| 조정 주기 (개월) | 7 | 발행일로부터 매 7개월 |
| 최저 조정가액 (원) | 12,148 | 최초 전환가액의 70% |
| 액면가 (원) — 조정 하한 | 500 | 전환가격이 액면 밑으로 못 내려간다 |
| IPO 조항 | 끈다 | 이미 상장사다. 비상장 RCPS 라면 켠다 |

시작·종료는 **발행일 기준 개월**이다. 평가기준일이 발행일보다 뒤여도 계약서 숫자를
그대로 넣으면 앱이 옮긴다.

## 7. 변동성

「변동성」 칸에 종가 파일을 넣으면 앱이 산출한다. **산출한 뒤 반드시 「이 변동성
적용」을 눌러야** 조서에 들어간다. 안 누르면 조서 만들기 자리에서 경고가 뜬다.

차바이오텍은 두 값이 크게 다르다.

| | σ | 파생상품부채 |
|---|---:|---:|
| 2년 주가로 산출한 관측 변동성 | 39.02% | 62.12 |
| 회사 인식액을 재현하는 변동성 | 21.12% | 50.66 |

**약 51억원 차이**다. 어느 값을 썼는지와 그 근거를 조서에 남겨야 한다.

## 8. 이자율

두 곡선 모두 **만기수익률(YTM)** 로 넣는다. 앱이 선형보간 → 부트스트래핑 →
선도이자율 순으로 처리한다.

| | 만기 1 / 2 / 3 / 5년 |
|---|---|
| 무위험 (국고채, 반기 이표) | 3.44 / 3.42 / 3.41 / 3.44 % |
| 위험 (연 1회 복리) | 15.0 % 평탄 |

위험 곡선 15.0% 는 관측값이 아니라 **회사 금액에서 역산한 값**이다. 주계약
54.1466 이 4.917년 만에 상환가액 107.6389 에 도달하려면 유효이자율이 14.998% 여야
한다. 실제 조서를 쓸 때는 등급별 회사채 수익률을 쓰는 것이 원칙이고, 역산은 인풋이
발행조건과 얼마나 떨어져 있는지 재는 자로만 쓴다. 「검산」 탭이 전체가 100 이 되는
스프레드를 역산해 넣은 값과 견줘 준다.

## 9. 확인할 자리

넣고 나면 이 순서로 본다.

1. **구성요소** — B0 → B1 → B2 → B3 이 계약과 맞는가. 옵션 값이 음수면 경고가 뜬다
2. **분리 판단** — 앱이 낸 결론이 사이드바 설정과 어긋나면 빨간 글씨가 뜬다
3. **검산** — 위험중립가중치가 0~1 안인가, 배분 합계가 100 인가, 역산 스프레드가
   넣은 값과 얼마나 떨어져 있는가
4. **회계처리** — 배분표·분개·거래원가 배분
5. **조서** — 값 조서와 수식 조서를 둘 다 내려받는다. 둘은 같은 값을 낸다

차바이오텍 조건으로 나오는 값은 이렇다 (발행총액 100 기준).

| | 값 |
|---|---:|
| B0 옵션 없는 우선주부채 | 53.5864 |
| B1 + 상환청구권 | 77.8830 |
| B2 + 전환권 | 104.2445 |

회사가 인식한 금액은 54.9435 / 50.6578 / (5.6013) 이다. 변동성 하나만 맞췄는데
나머지 둘이 따라온 것이라, 격자와 배분이 회사가 쓴 평가와 같은 구조라는 뜻이다.

## 10. 거래원가에서 갈리는 곳

이 앱은 거래원가를 요소별로 **비례배분**한다 (1032 문단 38). 주계약 몫은 부채에서
차감해 유효이자율에 녹이고, 파생상품부채 몫은 당기손익-공정가치 항목이라 즉시
비용으로 뺀다 (1109 문단 5.1.1).

차바이오텍은 354,599,783원 **전액을 할인발행차금**으로, 즉 주계약에만 넣었다. 앱은
0.4130 / 0.3839 로 나눈다. 어느 쪽을 쓸지는 판단이고, 조서에 적어 두면 된다.
