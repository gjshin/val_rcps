**보장수익률 칸을 비우면 안 된다.** 만료 시 자동전환이라 만기에 현금이 없지만,
전환권을 뺀 「옵션 없는 우선주부채」(B0)는 보통주가 될 수 없으므로 상환받는 것으로
잰다. 이 값이 B0 를 정하고, B0 가 주계약과 파생의 경계를 정한다. 회사는 상환청구
가능 최종일(2029-04-16)의 상환가액 **107.639%** 를 썼다 — 분기복리 1.5% 를 4.917년
굴린 값과 소수 넷째 자리까지 같다.

## 3. 회사가 인식한 금액

발행총액 44,499,682,128원을 100 으로 놓았다. 출처는 반기보고서(2024.06) 별도주석 23
과 사업보고서(2024.12) 별도주석 24 다. 지배기업이 직접 발행해 연결과 별도가 같다.

| | 원 | 100 기준 |
|---|---:|---:|
| 거래원가 (할인발행차금) | 354,599,783 | 0.7969 |
| 주계약 · 상환전환우선주부채 | 24,095,084,026 | 54.1466 |
| 파생상품부채 · 전환권 + 상환청구권 | 22,542,558,895 | 50.6578 |
| 파생상품자산 · 매도청구권 | (2,492,560,576) | (5.6013) |
| 상환할증금 | 3,399,286,218 | 7.6389 |

전환권은 **자본이 아니라 파생상품부채**다. 회사의 주석 문구는 이렇다.

> 전환권조정 금액 가운데, 전환권 가치 등 발행시점에 지분상품의 분류요건을 충족하지
> 못한 금액은 당기손익-공정가치로 측정되는 파생상품금융부채로 분류하여 인식하고
> 있습니다. 주계약인 부채요소는 상각후원가로 측정합니다.

7개월마다 70%까지 내려가는 리픽싱이 있어 확정수량 대 확정금액 요건을 깨기 때문이다.
이 앱의 **전환권 회계 분류 = 파생상품부채** 갈래가 그대로 맞는 사례다.

## 4. 맞춰 보기

주계약이 54.1466 에서 4.917년 만에 107.6389 로 붙으려면 유효이자율이 **14.998%**
여야 한다. 이것이 회사가 쓴 위험할인율이다. 그 값을 평탄한 위험 곡선으로 넣고,
무위험은 국고채(2024-05-16 전후) 3.4% 대를 넣었다.

남은 미지수는 변동성 하나다. 회사가 공시한 것은 「주가변동성은 과거 주가변동에
기초하여 추정」 이라는 문장뿐이고 수치가 없다. 그래서 **파생상품부채 50.6578 에
맞춰 σ 를 역산**했다.

```
보정 σ = 21.12%
B0 53.5864   B1 77.8830   B2 104.2442
```

| | 모델 | 회사 | 차이 |
|---|---:|---:|---:|
| 파생상품부채 (B2 − B0) | 50.6581 | 50.6578 | 맞춘 값 |
| **매도청구권 · 파생상품자산** | **5.1577** | **5.6013** | **−7.9%** |
| 주계약 (잔여, 거래원가 전) | 54.4996 | 54.9435 | −0.8% |

매도청구권과 주계약은 **맞추지 않은 값**인데도 회사 금액과 8% 안쪽에서 만난다.
변동성 하나를 맞췄더니 나머지가 따라온 것이므로, 격자·순차 차감·배분이 회사가 쓴
평가와 같은 구조라는 뜻이다. 순차 차감은 이렇게 나온다.

| | 값 |
|---|---:|
| B0 옵션 없는 우선주부채 | 53.5864 |
| B1 + 상환청구권 | 77.8830 |
| B2 + 전환권 | 104.2445 |
| 매도청구권 (20% 한도 · 유무가치비교) | 5.1577 |

한편 실제 주가로 산출한 변동성은 이보다 훨씬 높다. 2023-05 ~ 2024-05 종가 27개
(2주 간격, 네이버 금융)로 재면 **39.02%** 이고, 2년 주간 베타 회귀의 결정계수에서
되짚어도 38% 안팎이 나온다. 회사(또는 그 평가기관)가 쓴 21% 는 관측 변동성보다
낮다. 어느 쪽이 옳다고 이 문서가 정하지는 않는다 — 다만 **σ 를 21% 로 잡으면
파생상품부채가 50.66, 39% 로 잡으면 62.12 로 약 51억원 차이가 난다**는 사실은
조서에 적을 일이다.

### 기말 (2024-12-31) 은 맞지 않는다

주가 10,579원, 전환가액 15,639원으로 갱신하고 같은 σ·할인율로 다시 재면

| | 모델 | 회사 |
|---|---:|---:|
| 파생상품부채 | 33.4857 | 26.5464 |
| 매도청구권 | 1.3774 | 2.2301 |

모델이 7 포인트(31억원)만큼 높다. 역산해 보면 회사 금액을 재현하는 조합은
**할인율 12% · σ 14.85%** 이고, 할인율을 15% 로 두면 σ 가 3.7% 까지 내려가야 한다.
할인율 18% 에서는 σ 를 0 으로 해도 상환청구권만으로 29.45 라 목표를 넘는다.

회사가 기말에 어떤 가정을 썼는지 공시하지 않았으므로 여기서 더 좁힐 수 없다.
**발행일 평가는 재현되고, 기말 재평가는 가정이 공시되지 않아 재현되지 않는다** 가
이 사례의 결론이다.

## 5. 이 사례가 드러낸 앱의 한계

콜옵션 한 가지는 이 사례를 계기로 고쳤고, 나머지 둘은 남아 있다.

1. ~~제3자 지정 매도청구권을 RCPS 에서 못 넣는다.~~ **고쳤다.** 사이드바
   「콜옵션」이 세 갈래(없음 / 발행회사의 상환권 / 제3자 지정 매도청구권)가 되었고,
   제3자 지정을 고르면 전체 격자에서 재어 **파생상품자산으로 따로** 세운다
   (1109 문단 4.3.1). 한도·의무보유·세 평가방법도 함께 열린다.

2. **상각표가 만기 100 을 전제한다.** 이 계약의 부채요소는 2029-04-16 에 107.639 로
   끝난다. 상각표 시트의 유효이자율은 그 전제를 반영하지 못한다. 결산 회계처리는
   회계처리 탭의 「당기 이자비용」 표에 발행일 유효이자율(15.0%)을 직접 넣어 쓴다.

3. **배당가능이익 한도(상법 345조)를 무시한다.** 차바이오텍은 상환 재원을 만들려고
   주식발행초과금을 이익잉여금에 전입하겠다는 약정을 계약에 넣었다. 모델은 상환청구가
   언제나 가능하다고 보므로 상환청구권을 다소 높게 잡는 방향이다.
