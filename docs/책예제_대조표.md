## 1. 매도청구권 — 방법이 둘이고 7% 갈린다

책은 `[사례 4-4]` 를 두 파일로 나눠 같은 사채의 수의상환권을 두 방식으로 평가한다.

전제 · 액면 10,000 · 표면 0% · 보장 6% · 5년 · σ 40% · Rf 3% · Rd 7%
수의상환권 보장수익률 6.5% · 행사기간 1~2년차 · **전환억제 조건**

### 유무가치비교법

콜을 넣고 한 번, 빼고 한 번 돌려 차액을 본다.

```
CB without Call   13,060.17   ← 사례 4-1
CB with Call       9,863.70
수의상환권          3,196.47
```

`cb_app.py` 의 순차 차감(B2 → B3)이 이 방법이다.

### 옵션차익혼합할인법

콜을 **CB 가치를 기초자산으로 하는 별도의 미국형 콜옵션**으로 따로 평가한다.

```
구성비율(i,j)   = 지분가치(i,j) ÷ 전환금융상품가치(i,j)
혼합할인율(i,j) = 구성비율 × Rf_forward + (1 − 구성비율) × Rd_forward
페이오프(i,j)   = Flag(Call)=1 이면 MAX(전환금융상품가치 − 콜행사가, 0), 아니면 0
콜옵션가치(i,j) = MAX(페이오프, 다음 두 노드를 혼합할인율로 할인)
```

```
방법1 혼합할인율          2,971.02
방법2 지분·부채 분리 할인   2,979.66
(참고) 전액 Rf 할인       3,032.51
(참고) 전액 Rd 할인       2,909.87
```

방법2는 페이오프를 구성비율로 지분분·부채분으로 쪼갠 뒤 각각 Rf·Rd 로 할인한다.
두 방법 모두 Rf·Rd 전액 할인 사이에 놓인다.

### 왜 225 (7.1%) 갈리는가

유무가치비교법은 **전환억제 조건의 효과까지 콜 가치에 포함시킨다.**
콜 기간 중 전환이 막히면서 잃는 전환권 가치가 차액에 섞여 들어간다.
옵션차익혼합할인법은 콜옵션 자체만 잰다.

어느 쪽이 옳다기보다 **재는 대상이 다르다.** 보고서가 어느 방법을 썼는지
확인해야 하는 이유이고, 티사이언티픽에서 매도청구권이 공시 14.39 대
모델 13.53 으로 0.86 벌어졌던 것도 이 계열의 문제일 수 있다.

## 2·3. 상환할증금 — 우리 산식이 표면이자율을 무시한다

`[사례 5-7]` 이 상환할증금의 정본 산식을 준다.

```
각 회차 할증금률(t) = ((g − c) / m) × (1 + g/m)^(k−t)
총 상환할증금률     = Σ = ((g − c)/m) × ((1+g/m)^k − 1) / (g/m)
행사금액            = 액면 × (1 + 총 상환할증금률)
```

`g` 보장수익률 · `c` 표면이자율 · `m` 복리 횟수 · `k` 총 회차

미지급 보장수익률을 매 회차 적립해 만기까지 굴린 **연금의 미래가치**다.
시트는 IRR 로 검산한다 — `(1+IRR)^k = (1+g/m)^k` 가 성립한다.

### cb_app.py 의 현재 산식

```python
red        = 100 + (tm.ytm - tm.cpn)*100*(T + ey)      # 단리
put_amt(i) = 100*(1+eff)**(i*dt_ + ey)                  # 표면이자율 미반영
```

삼보모터스 공시 만기상환율이 **122.0190%** 이므로 책 산식이 맞다.

## 5. 전환억제 조건 — 구현 방식이 다르다

```
책   Flag(Conversion) = IF(Flag(Call)=1, 0, IF(전환기간, 1, 0))
```

콜 행사기간 **전체**에서 전환을 막는다.

계약이 "행사기간 종료일까지 30% 를 미전환 보유"인 티사이언티픽에는
우리 방식이 맞고, "콜 기간 중 전환 불가"인 계약에는 책 방식이 맞다.
**계약 문언을 보고 골라야 한다.**

## 6. IPO 리픽싱

`[사례 5-5]` 의 조건식.

```
리픽싱 여부 = AND(공모가액 × 70% < 조정전 전환가격,  주가 > 최소공모가격)
조정후 전환가격 = 리픽싱이면 공모가액 × 70%, 아니면 조정전 그대로
```

두 번째 조건이 IPO 성립 여부를 대신한다. 주가가 최소공모가격에 못 미치면
상장 자체가 무산되므로 조정도 없다.

`cb_app.py` 는 시가 연동 리픽싱만 다룬다. 트러스테이가 정확히 이 유형이었고
보고서는 "Refixing 변동 없음"으로 가정했다. 앱에 넣으려면 최소공모가격과
공모가 배수를 인풋으로 받아야 한다.

기능이 아니다.

## 고치면서 함께 잡은 것

**`build_xlsx` 의 만기상환금액이 경과기간을 빼고** 계산하고 있었다.
엔진은 `T + 경과연수` 를 쓰는데 값 조서는 `T` 만 써서, 평가기준일이
발행일보다 뒤일 때 조서와 화면의 숫자가 어긋났다.

**`eir_table` 도 옛 단리 산식을 쓰고 있었다.** 상각표가 만기상환금액을
따로 계산해, 표면이자가 있으면 격자와 다른 금액으로 상각됐다.
삼보모터스형에서 상각표 120.01 대 격자 122.03 으로 벌어졌다.

**상각 구간이 만기에 안 맞았다.** `nper = round(T/per)` 이라 잔존기간이
지급주기의 배수가 아니면 마지막 구간이 만기 전에 끝났다. 기말 장부금액이
만기상환금액과 0.07 어긋났다. 마지막 구간을 만기에 맞춰 이제 정확히 떨어진다.
남는 조각이 지급주기의 10% 미만이면 직전 회차에 붙인다 — 그러지 않으면
잔존 5.0027년·분기 지급에서 21회차가 1일짜리 조각으로 남았다.

| 삼보모터스 0%/4% | 122.0323 | 122.0323 | 21.65% |
